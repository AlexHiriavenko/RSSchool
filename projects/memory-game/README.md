# Memory Game

Игра на поиск пар: нужно открыть все 8 пар одинаковых карточек за наименьшее число ходов.

**Демо:** https://alexhiriavenko.github.io/RSSchool/memory-game/

## Возможности

- Поле 4×4: 16 карточек (8 пар эмодзи), перемешиваются при каждой загрузке страницы и новой игре.
- Один ход — открытие двух разных карточек. Совпавшая пара остаётся открытой, несовпавшая закрывается через 1 секунду, пока она открыта, другие карточки выбрать нельзя.
- Счётчики ходов и найденных пар.
- Кнопка «Новая игра» работает в любой момент: сразу сбрасывает поле и счётчики и отменяет таймер закрытия несовпавшей пары.
- Модальное окно победы с итоговым числом ходов (кнопки «Новая игра» и «Закрыть»).
- Таблица лидеров: 10 лучших результатов (место, ходы, дата ДД.ММ.ГГГГ), хранится в `localStorage`. Выше тот, у кого меньше ходов, при равенстве — у кого игра раньше.
- Модальные окна закрываются кнопкой, кликом по фону и клавишей Escape; пока окно открыто, страница под ним недоступна и не прокручивается.
- 3D-анимация переворота карточек.

## Технологии

HTML, CSS и JavaScript (ES-модули) без UI-библиотек и фреймворков. Вся разметка создаётся через `document.createElement` (обёртка `el` в `src/utils/dom.js`), `<body>` в `index.html` содержит только `<script>`. Сборка и dev-сервер — [Vite](https://vite.dev), деплой — `gh-pages`.

## Структура проекта

```
src/
├── index.js            # точка входа: memoryGame.init()
├── memory-game.js      # связывает логику, интерфейс и хранилище
├── config.js           # эмодзи и константы (задержки, размер таблицы, ключ localStorage)
├── core/               # логика без DOM
│   ├── game.js         # состояние и правила игры
│   ├── deck.js         # создание и перемешивание колоды
│   └── leaderboard.js  # чтение и запись результатов в localStorage
├── ui/                 # отображение
│   ├── header.js, board.js, stats.js
│   ├── modal.js        # общий компонент модального окна
│   ├── win-modal.js, leaderboard-modal.js
└── utils/              # dom.js, shuffle.js, format-date.js
styles/                 # CSS по компонентам
```

## Локальный запуск

Нужен Node.js 18+.

```bash
cd projects/memory-game
npm install
npm run dev
```

Откройте адрес из консоли, обычно `http://localhost:5173/RSSchool/memory-game/` (путь задан в `vite.config.js` через `base`).

Другие команды:

| Команда           | Назначение                                       |
| ----------------- | ------------------------------------------------ |
| `npm run build`   | production-сборка в `dist/`                      |
| `npm run preview` | локальный просмотр собранной версии              |
| `npm run deploy`  | сборка и публикация в `gh-pages` (`/memory-game`) |
